Cómo funciona

Tres pasos, y después no vuelves a pensarlo.

01

Dibuja el polígono

En el mapa de Portal Inmobiliario, ajustado alrededor del edificio que te interesa.

02

Conéctalo a tu bot

Pega la URL en Lindero, elige a qué chat de Telegram avisar y cada cuánto revisar.

03

Recibe el aviso

Solo cuando cambia algo real. El resto del tiempo, Lindero revisa por ti en silencio.

El panel administrativo real: conectar, pausar, editar y ver el estado de cada propiedad.

Sin servidores de por medio

Corre en tu propio equipo.

Nada de crear una cuenta ni de que un tercero sepa qué propiedades vigilas. Instalas Lindero una vez, con Docker, y es tuyo.

Gratis y de código abiertoTodo el código está en GitHub, para revisar, modificar o auditar.
Tus datos, en tu máquinaTodo vive en una base SQLite local. Nada sale de tu computador o servidor.
Sin límites artificialesCuantas propiedades quieras, cada una con su propio horario.
Instalación

Arriba en tres comandos.

Necesitas Docker Desktop instalado y abierto. El README trae la guía completa, paso a paso, pensada para cualquiera (no solo programadores).

# 1. clona el proyecto git clone https://github.com/facualex/portalinmobiliario_watch cd portalinmobiliario_watch # 2. completa TELEGRAM_BOT_TOKEN en .env cp .env.example .env # 3. arriba docker compose up -d --build
